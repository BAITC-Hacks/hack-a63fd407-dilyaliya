# Соответствие критериям HackAlem

Эта матрица описывает реализованные функции и способ проверки, а не обещает оценку жюри.

| Критерий | Свидетельство | Проверка |
|---|---|---|
| Задача и работоспособность, 25 | Полный pipeline, все узлы, кластеризация, top30, схема с направлениями | `sh run.sh`, поиск произвольного gid, `scripts/verify.py` |
| Техническая реализация, 25 | Метрики, правила версии 3, FIFO с учётом сумм, Louvain, паттерны, контроль граничных случаев | Код pipeline/, тесты, temporal_matches.parquet, analytics.json |
| README и воспроизводимость, 25 | Формулы, ограничения, платформы, офлайн-пакеты, манифесты, точные схемы | Пустая venv, `--no-index`, сравнение повторных результатов |
| Ценность и применимость, 15 | Приоритеты с объяснениями, карточка, история, экспорт, запрос белых пятен | Живой разбор трёх автоматически выбранных примеров |
| Развитие и оригинальность, 10 | Два сценария дневного порядка FIFO, чувствительность, случайный контроль удаления, помощник | Аналитические вкладки, README о 1 млн узлов |

## Обязательные артефакты

Исходники — pipeline/, app/, run_pipeline.py; README — корень; три CSV — output/; схема — docs/architecture.svg; пяти­минутное демо — output/demo.md и живой запуск. Подготовка сценария не заменяет фактическое выступление команды.

## Опциональные пункты

Обрыв графа, временные паттерны, повторные маршруты и циклы, относительные аномалии, удаление top-N, карточки и оценка полноты реализованы. Помощник отвечает на ограниченные вопросы локальными правилами и даёт переходы к узлам: **это не LLM и не следует представлять его как agentic AI**. Опциональный AI-пункт может оцениваться жюри отдельно по их трактовке.

## Границы доказательств

Нет ground truth: не заявляем accuracy. Не установлена виновность и не доказано происхождение каждой суммы. Результат теста на текущей macOS не доказывает выполнение на Windows/Linux: для них включены пакеты, но эти ОС здесь не запускались. Нет защищённого банковского аудита и многопользовательского хранилища — для хакатонного батча это не требовалось. Score отражает силу правила и приоритет ручной проверки.
