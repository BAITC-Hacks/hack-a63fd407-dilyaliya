## Расчёт и регрессионные тесты

17/17 тестов прошли. Сквозные проверки запускают новый пересчёт во временный каталог, затем проверяют реальные выходные файлы. Проверены оба проблемных распределителя, консолидация, требования координатора, граничные условия, изоляты, обратные рёбра, циклы, самопереводы, точность int64, CSV, гипотезы потоков, сумма вкладов и сценарии весов. Время тестового набора около 4–5 секунд.

Полный пересчёт от Parquet до HTML и всех выгрузок занимает в проверенных запусках примерно **1,8–2,4 секунды** внутри точки входа; это существенно ниже 300 секунд. Точное время последнего запуска и версии зависимостей записаны в `output/run_report.json`. Проверен также запуск через `.\run.bat`.

Сохранены все 2248 узлов, 81 seed, 19 изолятов, 444 листа глубины 4. 35 полных компонент, 16 компонент с рёбрами, 105 кластеров. Итоговые роли: terminal 1527, peripheral 542, distributor 126, transit 32, consolidator 20, coordinator 1. Обязательные схемы трёх CSV не расширены; evidence непустой, не длиннее 200 символов.

## Чувствительность приоритета

Проверены 14 сценариев: база, каждый из шести весов ±20% и вариант без роли. При изменении одного веса сохраняются **27–29 из 30** участников базового топа, максимальный сдвиг базовых участников — 7 мест. Без вклада роли сохраняются 24 из 30, максимальный сдвиг — 21 место. Это показывает остаточную чувствительность, поэтому точный порядок нельзя считать объективной истиной.

Разборные узлы: распределитель с 116 получателями — место 13, диапазон 11–19; консолидация `100000002398779100` — место 5, диапазон 2–7; coordinator `100000008165763100` — место 14, диапазон 12–18. Диапазоны включают вариант без роли. Полная таблица в `ranking_sensitivity.csv`.

## Живой браузерный прогон

Проверено через локальный HTTP на 127.0.0.1 и интерфейс браузера:

- Загрузка графа и всех 30 кандидатов; поиск длинного gid без потери цифр.
- Карточки распределителя, консолидатора, пограничного terminal и изолированного seed.
- Путь от seed, переход к следующему кандидату, сохранение списка, полный сброс.
- Фильтры кластера и роли, количественная гипотеза кластера, отсутствие пути по обратному ребру в тестах.
- Ошибка неизвестного gid; переключение к следующему кандидату после неё.
- Отображение на узком экране, отдельная вертикальная раскладка пути, сохранение трёх панелей на обычном экране.

В проверенной сессии журнал браузера не содержал ошибок или предупреждений. Синтаксис JavaScript дополнительно проверен `node --check`. SVG-схема отрендерена и визуально просмотрена. Интерфейс не требует CDN, внешних API или веб-сервера при открытии HTML-файла.

Событие скачивания TXT встроенный браузер не подтвердил: ожидание завершилось таймаутом. Поэтому добавлен и проверен запасной способ: кнопка одновременно открывает готовый текст карточки для копирования. Сохранение файла в обычном внешнем браузере отдельно не проверялось.

## Офлайн-воспроизведение

Архив распакован в новую папку без `.venv`. Создано новое окружение, зависимости установлены с `pip --no-index --find-links wheelhouse`, выполнен полный расчёт. Первая проверка установки и расчёта заняла около **40 секунд**, без скачивания зависимостей. Все файлы проверены по SHA-256 манифеста.

Свежие `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`, `ranking_sensitivity.csv` и `graph.html` побайтово совпали с упакованными результатами. Локальные журналы — `.verification/offline-install.log`, `.verification/offline-verification.json`. Для повторения: `python tools/verify_bundle.py`; Python 3.12 x64 должен быть установлен заранее.

Это проверка чистого окружения на текущей машине, а не на отдельном ноутбуке жюри. Linux/macOS wheels и производительность на миллионе узлов не проверялись. Точность ролей, устойчивость к порогам/разрешению кластеризации и фактическая экономия времени аналитика без размеченных данных и пользовательского исследования не заявляются.
