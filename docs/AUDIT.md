## Ограничения и корректность

444 листа depth4 помечены как обрыв с score≤0,25. Все 19 изолированных seed сохранены; 31 seed не имеет исходящих — соответствует предупреждениям задания. Полный граф содержит 35 компонент: 16 с рёбрами и 19 изолятов. Сумма рёбер 365 890 012,01 KZT соответствует округлённой сумме из документа.

Выявленных списков «правильных gid», внешних атрибутов клиентов и сетевых обращений для основной аналитики нет. Файлы с конкретными gid в output — результаты вычислений, а тестовые целые ID — синтетические фикстуры. Папка starter содержит исходные заглушки организаторов и не является точкой запуска готового решения.

Сохранение сумм и временное направление FIFO проверены отдельно по каждому узлу, операции и сценарию. Циклы и повторные маршруты — кандидаты, а не доказательство движения одной суммы. Score не выдаётся за вероятность нарушения; ground truth отсутствует.

## Переносимость и изменения при проверке

Исправлены два обнаруженных недостатка: генератор манифеста теперь записывает пути через `/` на любой ОС; тест путей сравнивает объекты Path и больше не требует Unix-разделителей. Добавлен регрессионный тест генерации манифеста. Все 40 wheel-файлов в пяти наборах проверены по SHA-256.

README дополнен отдельными разделами macOS, Windows и Linux: проверка Python, запуск из нужной папки, адрес сайта, остановка, пакетный режим, другой порт и диагностика. Для Linux указаны venv/ensurepip, для Windows — py launcher и команды PowerShell/cmd.

Нативная работа реально проверена только на macOS arm64. Windows/Linux/Intel Mac и Docker в этой среде не запускались; Docker отсутствует. Офлайн-требование закрывает включённый нативный комплект, при заранее установленном Python. Docker без подготовленного образа требует первоначальной загрузки базового образа, поэтому не должен быть единственным способом сдачи при запрете интернета.
